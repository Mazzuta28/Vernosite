САЙТ «СТУДИЯ ЗНАНИЙ ВЕРНО» — публикация на GitHub Pages
1. Создайте на github.com новый репозиторий (Public), например "verno".
2. Add file → Upload files: перетащите index.html И ПАПКУ assets (с файлами внутри). Commit changes.
3. Settings → Pages → Source: Deploy from a branch, Branch: main, папка / (root) → Save.
4. Через 1–2 минуты адрес: https://ВАШ-ЛОГИН.github.io/verno/
Замените в подвале [ГОД] и [ВАШЕ ИМЯ] (в index.html, строка с "©").
Адрес сервиса викторин (https://victorina-2026-7.onrender.com) стоит в index.html — замените при смене адреса.
Плитки в «Устном счёте» — по одной на викторину версии 3.23, у каждой свой знак (6×7, 42÷6, a(b+c) и т. д.). Портреты математиков используются не на сайте, а как персонажи для учеников в самих викторинах (обновление 3.24).
